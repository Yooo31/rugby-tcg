# Rugby TCG

Jeu de cartes à collectionner sur les clubs de rugby français, du Top 14 à la Régionale 3. Application web installable (PWA), pensée pour le mobile.

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm check    # typecheck + lint + tests + build
```

Les données sont fictives pour l'instant (clubs en dur, progression dans le navigateur).
